# 🌐 DomainDrop — Telegram Mini App (Domain Empire)

Интеллектуальная коллекционная игра внутри Telegram, в которой игроки исследуют редкие комбинации букв и цифр, решают логические задания, собирают альбомы и развивают собственную библиотеку редких игровых имён.

---

## 🌟 Основные механики

1. **Коллекционирование редких имён (1–8 символов)**
   - Каждое имя — полноценный коллекционный объект с процедурным визуальным узором, уникальным `instance_id` (например, `DOM-000101`), категорией и игровой зоной (`TECH`, `ARCADE`, `CORE`, `ECHO`, `NEXUS`).
   - 6 уровней редкости: Common, Uncommon, Rare, Epic, Legendary, Secret.
   - Имена не являются настоящими интернет-доменами и не дают на них прав.

2. **Domain Scanner — интеллектуальные испытания**
   - Головоломки на поиск палиндромов (`RADAR`, `ROTATOR`, `10001`), последовательностей цифр (`888888`), самых коротких названий (`Q7`) и смешанных паттернов (`NEO99`).
   - Предсказуемая система наград без скрытых вероятностей и платных лутбоксов.

3. **Кинематографическая анимация открытия (Reveal)**
   - Сканирующий луч, посимвольное проявление с адаптивным размером шрифта и конфетти при открытии Epic/Legendary карт.

4. **Коллекционные альбомы**
   - Фиксированные альбомы: Short Names, Numeric & Cyphers, Mirror Palindromes, Tech Architecture, Arcade & Gaming, Genesis Archive.
   - Завершение открывает награды: Domain Coins (DC), опыт и знаки отличия.

5. **Domain Workshop (Мастерская)**
   - Детерминированные рецепты крафта: трансмутация дубликатов в гарантированные предметы редких категорий и зон.

6. **Экономика Domain Coins (DC)**
   - Внутриигровая валюта, зарабатываемая только за реальные действия: ежедневный вход (+10 DC), решение задач (+10–20 DC), завершение альбомов.

## 🤖 Команды Telegram Бота

### `/start`
> Отправляет приветственное сообщение, рассказывает об основных механиках игры, коллекциях и логическом сканере, а также прикрепляет интерактивную кнопку запуска:
> **«🌐 Играть в DomainDrop»** (`web_app`).

### `/goal`
> Отправляет дорожную карту и цели коллекционера:
> - Достижение новых уровней коллекционера
> - Завершение альбома зеркальных палиндромов (*Symmetry Seeker*)
> - Сбор 15 коротких имён
> - Квантовый крафт в мастерской
> - Описание миссии проекта DomainDrop по созданию честной игры без азарта

### `/scanner`
> Быстрый переход к активным логическим испытаниям в Mini App.

### `/help`
> Руководство по правилам игры, категориям и безопасности.

### `/top`
> Таблица лидеров коллекционеров по уровню и собранным предметам.

## 🛠️ Стек технологий

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, Canvas Confetti.
- **Audio & Haptics:** Web Audio API (процедурный синтез звуков), Telegram WebApp HapticFeedback API.
- **Telegram SDK:** `window.Telegram.WebApp` (Ready, Expand, Fullscreen, ClosingConfirmation, Safe Areas).
- **Backend:** Node.js, Express, HMAC-SHA256 валидация `initData`, JSON хранилище.
- **Деплой:** GitHub + Render Web Service.

## 🚀 Локальный запуск

```bash
# Установка зависимостей
npm install

# Сборка и проверка типов
npm run build

# Запуск локального сервера
npm start
```
Приложение откроется на `http://localhost:10000` (или `http://localhost:5173` в режиме `npm run dev`).
